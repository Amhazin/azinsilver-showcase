# Feature Overview

AzinSilver includes several connected product and operational areas.

## Customer-facing areas

- product browsing and product pages
- customer account
- checkout and order creation
- order history
- payment workflow

## Commerce areas

- product catalog management
- pricing logic
- inventory logic
- product availability controls
- order workflow

## Operations

- platform administration
- shop operations
- product management
- pricing and inventory management
- order management

## Engineering practices

- versioned API design
- frontend / backend separation
- automated backend tests
- Git-based development
- structured planning and validation
- AI-assisted software development

The full implementation remains private. This repository is a portfolio-level showcase only.
